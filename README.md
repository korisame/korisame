# Shaun Gioele Gori

Independent developer working on efficient local AI, hybrid decision models and practical agent tools.

## Research in progress

I'm exploring how small decision models, language models and deterministic tools can work together on everyday hardware. The focus is on reproducible evaluation, useful context and reliable actions.

- **Mac hybrid System-1 / LLM:** experimenting with fast decisions alongside language generation on Apple silicon.
- **Dell long-context lab:** testing Bonsai-based local workflows, context handling and source-grounded answers on constrained GPU hardware.
- **Linux Pilot:** investigating local decision models for browser and desktop automation, including observation, action selection and verification.

These are experimental projects under development. Model releases and papers are still being prepared; individual development results are not claims of general reliability.

## Public tools

**[VivaMem](https://github.com/korisame/vivamem)** is an agent-memory project built around local SQLite storage, temporal facts, provenance and token-budgeted context compilation. Optional LLM-assisted steps use external Claude/Codex subscription CLIs; those steps are not entirely local or free computation.
